# The dataset

This directory is the analytical layer behind the ten timelines. The site is
the communication layer. The two are deliberately separate: the site can be
read as a story, while the data can be inspected, filtered, and recomputed.

## Files

| File | Grain | Rows | Purpose |
|---|---|---:|---|
| `events.csv` | one world chapter | 90 | The nine moments shown for each world |
| `worlds.csv` | one world | 10 | World metadata, order, and timeline start |
| `sources.csv` | one citation | 36 | Sources used by the event table |
| `analysis.json` | generated | — | Derived metrics and chart-ready data |
| `js-events.json` | generated | — | Presentation export used by the data tests |

`analysis.json` is generated by `python analysis/audit.py`. It is committed so
the static site does not need a build step. `js-events.json` is generated by
`node tools/export_events.mjs data/js-events.json` and is used only to check
that the published copy still matches the chapter text rendered by the site.

## `events.csv`

One row per chapter. The key is `event_id`; `(world, chapter)` is also unique.

| Column | Meaning |
|---|---|
| `event_id` | Stable key, `world_NN` |
| `world` | World key; foreign key to `worlds.world` |
| `chapter` | 0–8, in display order |
| `layout_at` | Editorial position on the line, 0–1. **Not time.** |
| `time_label` | Human-readable label shown on the site |
| `years_ago` | Numeric age in years before 2026; `0` means Today |
| `years_ago_low` / `years_ago_high` | Published range, when sources disagree; blank otherwise |
| `time_kind` | `deep_time`, `dated`, or `today` |
| `event` | Short chapter title |
| `note` | One-line caption |
| `event_class` | `cosmic`, `formation`, `geological`, `impact`, `climate`, `life`, `observation`, `mission`, or `status` |
| `evidence` | `observed`, `inferred`, `modeled`, `hypothesis`, or `state` |
| `status` | `past`, `current`, `ongoing`, or `planned` |
| `source_id` | Foreign key to `sources.source_id` |
| `source_note` | Why a range or caveat exists, when relevant |
| `as_of` | Snapshot date for “Today” and current states |

## `sources.csv`

| Column | Meaning |
|---|---|
| `source_id` | Stable key |
| `title` | Source title |
| `publisher` | NASA, ESA, journal, or institution |
| `url` | Public URL |
| `kind` | `overview`, `mission`, `paper`, `dataset`, `program`, or `reference` |
| `notes` | What the source supports, including caveats |
| `accessed` | Access date |

The source table is intentionally uneven in depth. NASA overview pages support
broad world history; mission pages support dated observations and spacecraft
events; papers support claims where the literature is contested. A single
overview is not evidence that every sentence on a world page is exact.

`python tools/check_sources.py` rechecks every URL. Publisher bot protection
(401/403/429) is reported as blocked rather than broken.

## Units and conventions

- Ages are **years before 2026**. `4.6 billion years ago` is `4,600,000,000`.
- Dated observations use `years_ago = 2026 - year`; the table also preserves
  the original `time_label`, so `1610` remains legible.
- “Today” is a snapshot at `2026-10-27`, not a live feed. It is encoded as
  `years_ago = 0` and `time_kind = today`.
- `layout_at` is an **editorial coordinate** between 0 and 1. It is monotonic
  within a world and should never be used to calculate elapsed time.
- A blank range means “no numeric range assigned,” not “certain.”

## What this dataset is not

This is a **curated, comparative sample**: nine chapters per world, chosen to
tell a coherent story. It is not a random sample of planetary events, a
complete chronology, nor a measurement series. The evenly spaced chapter count
is a format constraint, not a finding.

The largest gap in each world is a property of the sample. It is not evidence
that nothing happened during that interval. Gap statistics keep deep/deep and
dated/dated intervals separate; boundary intervals (deep-to-dated and
dated-to-Today) are classified as mixed and are not pooled into either median.
Read `reports/time-axis-audit.md` for the full limitations.

## Provenance and corrections

The chapter text and editorial positions come from the site's presentation
data (`planet-eras.js` and `earth-eras.js`). Numeric ages, ranges, event classes,
evidence grades, and sources were added for this audit. Known editorial
corrections are visible in the CSV, including:

- Saturn 1655: Titan was discovered in 1655; the ring interpretation followed
  in 1659.
- Moon 1972: Apollo 17 returned the last samples, not Apollo 11.
- Mercury Today: BepiColombo orbit insertion is planned for November 2026.
- Earth Today: population is recorded as 8.2 billion (UN WPP 2024).
- Sun 4.1 Ga: “main sequence” replaces the ambiguous “steady state.”

If a claim is wrong, correct the CSV and its source first, then regenerate the
analysis and the site copy.

## Reproduce

```bash
python -m pip install -r requirements.txt
node tools/export_events.mjs --check   # presentation/dataset parity
python analysis/audit.py --check       # committed analysis is current
python -m pytest -q                    # schema, parity, analysis, pages
```

Rebuild the generated artifacts after changing a table or chapter:

```bash
node tools/export_events.mjs data/js-events.json
python analysis/audit.py
```
